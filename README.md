# Shahrukh Malick, Portfolio

Personal portfolio site. One file, no build step, no dependencies.

Live site: `https://YOUR-USERNAME.github.io/REPO-NAME/`

## Files
- `index.html`: the whole site (HTML, CSS, JS)
- `.nojekyll`: tells GitHub Pages to serve the files as-is

## Deploy with GitHub Pages
1. Put these files in the root of a public repository's `main` branch.
2. Open the repo's **Settings, then Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then Save.
4. The site goes live in about a minute.

Name the repo `YOUR-USERNAME.github.io` to get the shorter address `https://YOUR-USERNAME.github.io/`.
